# How to falsify CWR

CWR should be evaluated as a narrow robustness mechanism, not as a generally superior classifier.

## Core hypothesis

Let a shared latent process be observed through several local views:

\[
x_i = f_i(z) + \epsilon_i.
\]

The target regime is:

\[
z \text{ remains approximately stable}
\]

while one local mapping changes:

\[
f_i \rightarrow \tilde f_i.
\]

CWR predicts that conditionally realigning the changed local view should preserve downstream behavior better than freezing the old map or globally refitting the full representation.

## Primary falsification target

Define degradation under drift:

\[
\Delta_{\text{drift}}
=
\text{performance}_{\text{stable}}
-
\text{performance}_{\text{drift}}.
\]

The core prediction is:

\[
\Delta_{\text{drift}}^{\text{CWR}}
<
\Delta_{\text{drift}}^{\text{baseline}}.
\]

This does **not** imply:

\[
\text{performance}_{\text{stable}}^{\text{CWR}}
>
\text{performance}_{\text{stable}}^{\text{baseline}}.
\]

## Strong falsification experiment

A strong experiment should:

1. use external multiview data not generated by the CWR authors;
2. freeze the CWR method and hyperparameters before observing the prospective test;
3. keep the underlying label/task process fixed;
4. change only one local observation mapping;
5. compare with frozen CWR, GCCA, PCA/ALS or stronger relevant baselines;
6. match adaptation, data, and compute budgets;
7. use independent subjects/environments as the inferential units;
8. report paired effect sizes and nonparametric paired tests;
9. report stable-condition results;
10. report detector false-positive rates.

## Results that would count against CWR

Any of the following would weaken or falsify the claimed mechanism:

- adaptive CWR does not outperform frozen CWR under frame drift;
- CWR does not reduce drift degradation relative to strong multiview baselines;
- gains disappear when data/compute budgets are matched;
- the detector frequently realigns stable views;
- robustness gains require post-hoc tuning on each new dataset;
- the same qualitative effect fails to replicate across independent domains.

## Current evidence boundary

The repository contains tests on real MHEALTH and PAMAP2 sensor recordings.

However, the 3D frame rotations and axis-loss perturbations used in the key stress tests are experimentally injected. They are controlled robustness tests, not naturally documented sensor-reorientation events.

A particularly valuable future falsification test would use naturally occurring calibration or orientation drift.
